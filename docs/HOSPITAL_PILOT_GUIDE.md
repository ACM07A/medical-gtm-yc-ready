# Hospital Pilot Guide

Start at `/hospital`.

The pilot workflow shows:

- International patient inbox.
- Pipeline by stage.
- SLA and stale-case indicators.
- Hospital task board.
- Synthetic revenue view.
- Clinical review status owned by hospital reviewers.
- Estimate release through human approval.

Pilot prerequisites for real use:

- Hospital DPA and operating SOP.
- Named international patient desk users.
- Clinical reviewer workflow.
- Secure document exchange.
- Approved communication templates.
- Clear commercial terms and patient consent language.
